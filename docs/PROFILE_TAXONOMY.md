# Profile Taxonomy

## Etapa 5.1

Taxonomia controlada para perfis monitorados do Caliber Orbit.

A classificação é feita no nível do perfil, não no nível de cada Reel.

## Nichos principais

Valores conceituais permitidos:

- Gestão
- Financeiro
- Vendas
- Liderança
- Empreendedorismo
- Estratégia
- Comercial
- Marketing

Cada perfil deve possuir um único `niche` principal.

Assuntos secundários devem usar:

- `category`;
- `tags`.

## Regras de tags

Tags devem ser:

- lowercase;
- curtas;
- sem duplicação;
- de 3 a 6 quando houver evidência suficiente.

Exemplos:

- gestão;
- financeiro;
- vendas;
- liderança;
- estratégia;
- cultura;
- processos.

## Limitação

Esta taxonomia é curadoria administrativa de perfil.

Ela não substitui semantic feature extraction por Reel.

Um perfil pode publicar sobre vários assuntos; nesta etapa, o filtro de /trends usa a linha editorial principal e tags do perfil monitorado.
